# Roguelike Survival Shooter

**Developer:** Rui Tao  
**Date:** December 14, 2025  
**Engine:** Unreal Engine 5.5  
**Technologies:** Blueprints, PaperZD

## Overview

Roguelike Survival Shooter is a 2D survival shooter independently developed using Unreal Engine 5.5 and Blueprint Visual Scripting.

The objective is to survive as long as possible while enemies continuously spawn and pursue the player. Players earn higher scores by surviving longer, while the game's difficulty progressively increases.

The game includes a main menu, gameplay interface, credits page, background music, and sound effects.

## Gameplay Features

- **Enemy AI:** Continuous enemy spawning and Blueprint-based player pursuit.
- **Combat:** Player movement, shooting, and projectile collision detection.
- **Health System:** Player health management and game-over conditions.
- **Scoring:** Survival-time-based scoring with progressively increasing difficulty.
- **User Interface:** Main menu, gameplay UI, and credits page.
- **Audio:** Background music and sound effects.

## Installation and Setup

### Option 1: Play the Packaged Game

A standalone Windows version has been developed and packaged.

The executable game is not currently included in this repository. A downloadable build may be provided through GitHub Releases.

### Option 2: Run in Unreal Engine

1. Install Unreal Engine 5.5.
2. Install a compatible version of the PaperZD plugin.
3. Clone or download this repository.
4. Open `GameProducer.uproject`.
5. Load the main menu map and start the game.

**Note:** PaperZD is a third-party dependency and is not included in this repository.
